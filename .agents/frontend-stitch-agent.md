## 1. Design System Anchor: Autonomous Kinetic Precision
All components, layouts, and interactive micro-interactions must adhere to the design specifications defined in `Design.md` (derived from Stitch Project `BnB`):
- **Primary Brand Color:** Deep Oceanic Teal (`#0f766e` / `#005c55`)
- **Secondary Slate:** `#0f172a` (Buttons, headlines, high-contrast badges)
- **Background Canvas:** `#f8f9ff` / `#ffffff`
